# Famille Connect

---



**

> Crée une application web mobile (format smartphone) de mise en relation d'urgence entre des familles (seniors) et des étudiants, inspirée du modèle Uber. L'interface doit être très épurée, moderne, avec de gros boutons et des textes très lisibles pour les seniors.

> L'application doit proposer deux modes via un sélecteur :

> 1. MODE FAMILLE / SENIOR :

> 

> 

> * Écran 1 : Un grand bouton central "Déclarer une urgence".

> * Écran 2 (Formulaire simple) : Un menu pour choisir le besoin (Compagnie/Présence, Courses urgentes, Pharmacie, Aide au repas), une case pour l'adresse et une case pour le numéro de téléphone. Un bouton "Lancer la recherche".

> * Écran 3 (Attente) : Un message "Recherche d'un étudiant à proximité..." avec une animation de chargement. Dès qu'un étudiant accepte, afficher sa fiche (Prénom, photo, note de 4.9/5) et un bouton "Appeler l'étudiant".

> 

> 

> 2. MODE ÉTUDIANT :

> 

> 

> * Écran 1 : Un bouton pour basculer entre "En ligne" (disponible) et "Hors ligne".

> * Écran 2 (Liste des demandes) : Voir les urgences actives envoyées par les familles avec le type de besoin et la ville.

> * Écran 3 (Détail) : Quand l'étudiant clique sur une demande, il voit un gros bouton vert "Accepter la mission". Une fois accepté, cela affiche l'adresse exacte et le téléphone de la famille.

> 

> 

> Génère une interface fonctionnelle avec des données fictives pour que je puisse tester le parcours des deux côtés.
